             UI 按鈕功能說明
          

          

            

              
              

                專案列表抽屜
                
點擊展開左側專案管理面板，可搜尋、切換全域或單一專案視角，查看專案技能與文件。

              

            

            

              
              

                新增專案資料夾
                
彈出 macOS 原生 Finder 資料夾選取視窗，快速引入本地 repository 並鎖定路徑。

              

            

            

              
              

                新增任務 (New Task)
                
位於待處理欄位頂部，點擊開啟任務表單建立需求，可指派優先級 (P0~P3)、所屬專案與標籤。

              

            

            

              
              

                搜尋與優先級篩選
                
即時過濾看板卡片標題、需求描述與優先級等級，支援鍵盤 Tab 快速跳轉。

              

            

            

              
              

                立即指派 (AI 派工)
                
一鍵複製巡檢指令或觸發 AI 開工，將任務直接推入執行管道。

              

            

            

              
              

                封存任務庫
                
查看與管理歷史已結案任務，隨時可還原或檢視過去的執行日誌與 Git 異動紀錄。

              

            

            

              
              

                系統與偏好設定
                
自訂資料庫儲存目錄、深淺外觀主題、統一字級調整與切換 CLI Agent / AI 輪巡雙軌開工引擎。
